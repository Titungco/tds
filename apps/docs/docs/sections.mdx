# Sections (tds/digital)

Composed, CMS-agnostic sections built from `tds/ui` primitives. Every
section is presentational only — it takes plain props (or an array of
`PostSummary` objects) and renders JSX. None of them fetch data or import a
router; a consumer (a WordPress block, a Next.js page, ...) supplies the
data and, where relevant, a `linkComponent` for routing.

| Component | Purpose |
| --- | --- |
| `HeroBanner` | Eyebrow + title + description + up to two CTAs, with an optional media slot. |
| `Navigation` | Site header: logo, nav links, optional CTA button. |
| `LatestNews` | Curated highlight grid for a handful of featured posts. |
| `PostList` | General-purpose post archive/listing, with optional pagination. |

Every example below renders the real `@tds/digital` component.

`media` accepts any `ReactNode` (an illustration or screenshot) rendered
beside the copy on wide screens; omit `primaryAction`/`secondaryAction` for
a copy-only hero.

## LatestNews

A curated highlight grid for a handful of featured posts (e.g. the 3 most
recent). For a full paginated archive, use `PostList` instead.

<Example fullWidth>
  <LatestNews title="Latest from the blog" posts={samplePosts} />
</Example>

```tsx
import { LatestNews, type PostSummary } from "@tds/digital";

const posts: PostSummary[] = [
  {
    id: "1",
    title: "Why we rebuilt our design system on MUI",
    excerpt: "The tokens, the tradeoffs, and what we'd do differently.",
    href: "/blog/rebuilding-on-mui",
    date: "Sep 12, 2026",
    imageUrl: "/img/blog/rebuilding-on-mui.png",
  },
  // ...
];

<LatestNews title="Latest from the blog" posts={posts} />;
```

## PostList

General-purpose post archive/listing, with optional pagination. Every post
gets equal billing (unlike `LatestNews`' curated highlight layout). The
pagination control below is fully live — clicking a page number updates
real component state.

<Example fullWidth>
  <PostListDemo />
</Example>

```tsx
import { useState } from "react";
import { PostList, type PostSummary } from "@tds/digital";

function BlogArchive({ posts, totalPages }: { posts: PostSummary[]; totalPages: number }) {
  const [page, setPage] = useState(1);

  return (
    <PostList
      posts={posts}
      pagination={{ page, totalPages, onPageChange: setPage }}
    />
  );
}
```

`onPageChange` only updates local state here — whether that re-queries the
server for the new page (a fresh server-render) or hydrates client-side
pagination is entirely up to the consumer. `PostList` has no opinion on it.

## Router-agnostic links

`Navigation`, `LatestNews`, and `PostList` accept an optional
`linkComponent` prop so you can swap in a router's `Link` (Next.js, React
Router, ...) — it defaults to a plain `<a>`.

```tsx
import NextLink from "next/link";
import { Navigation } from "@tds/digital";

function RouterLink({ href, children, className }: { href: string; children: React.ReactNode; className?: string }) {
  return (
    <NextLink href={href} className={className}>
      {children}
    </NextLink>
  );
}

<Navigation links={links} linkComponent={RouterLink} />;
```

further interactive examples.
